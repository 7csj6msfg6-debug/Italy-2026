ITALY 2026 — ADD TICKETS FROM IPHONE

New Wallet feature:
- Tap Wallet > Add a ticket
- Choose a PDF or image from the iPhone Files picker
- Select its category, name, date and time
- The document is stored offline in IndexedDB on that device

Privacy and backup:
- Imported files are not uploaded to GitHub or any server
- Imported files do not sync to another phone
- Clearing Safari website data or removing site storage may delete them
- Keep original ticket files in the iPhone Files app as a backup
