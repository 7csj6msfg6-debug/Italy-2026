ITALY TRIP 2026 — ROUTE MODE UPDATE

This release adds one feature only: Route Mode.

What it does:
- Start Route Mode from any itinerary day
- Shows the current unfinished stop
- One-tap Maps when a map link exists
- Mark the current stop complete
- Automatically advances to the next stop
- Visual numbered route and daily progress
- Choose another day inside Route Mode

Upload every file in this folder to the root of your existing GitHub repository and replace the old files.
Then refresh the GitHub Pages site in Safari, fully close the Home Screen app, and reopen it.
