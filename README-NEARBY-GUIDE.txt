NEARBY GUIDE UPDATE

Added a Nearby tab inside Guide.

Features:
- Use my location (requested only after tapping the button; never saved)
- Near hotel and Near today's plan fallbacks
- Automatic closest-city selection for live location
- Filters for Meals, Quick stops, Drinks, and Official Picks
- Approximate distance sorting for curated Venice, Florence, Rome, Naples, and Capri places
- Walking Directions opens Google Maps for the exact route
- Custom places can participate when their Google Maps URL contains latitude/longitude

The app cache version was updated so GitHub Pages devices receive this build.
