# Italy 2026

Personal Italy trip companion web app for the September 2026 itinerary.

The app includes the day-by-day itinerary, Wallet and private local attachments, city food guides, Route Mode, transportation timeline, Trip Readiness, weather, currency conversion, spending tools, and saved places.

## Deployment

The app is deployed from the `main` branch with GitHub Pages.

Core application files live at the repository root. Private Wallet attachments and other personal app data are stored locally on the user's device and are not committed to this repository.
