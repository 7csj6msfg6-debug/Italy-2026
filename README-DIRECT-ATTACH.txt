WALLET DIRECT ATTACHMENT UPDATE

Every existing reservation card now includes its own Upload file button. PDFs and images selected there are stored locally on that iPhone and remain attached to that exact reservation card. Multiple files can be attached, opened, or deleted.

This is an app-code-only update. Existing PDFs in the GitHub tickets folder did not change, so you do not need to upload the tickets folder again.

Local files are not synced or uploaded to GitHub. Keep originals in Files/iCloud. Clearing Safari website data, changing site URLs, or changing devices can remove local copies.
